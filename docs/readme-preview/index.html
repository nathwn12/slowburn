Slowburn

Your music room: a Windows player with studio-grade Slow + Reverb and an A-B loop built for practice.

  • Slow + Reverb per track
  • A-B loop saved per track
  • Four skins incl. AMOLED
  • Mini mode for focus
  • Windows 10/11 64-bit

Built for musicians who practise, not just press play — drill the same four bars for an hour and it still looks good doing it.

Why this exists

Built for musicians who practise, not just press play. Two tools do the heavy lifting - everything around them is designed to look good while you drill the same four bars for an hour.

1 — Slow + Reverb, done right

Drop the speed to learn a part, wash it in reverb, all inside the player. Remembered per track, fine 1% steps, one-click reset to dry.

2 — A-B repeat worth using

Mark any passage on the seek bar, loop it, clear with \. Loops are saved per track, re-apply on reopen, with a library filter for tracks that have one.

Features

Player

  • Slow effect + Reverb intensity in fine steps, one-click reset to dry, per-track memory
  • A-B loop right on the seek bar, saved per track with auto-apply
  • Stop after current for clean endings to a practice run
  • Drag and drop audio files anywhere onto the player to queue them
  • ReplayGain support for even loudness
  • Explicit queue view with drag-to-reorder, never-blank empty state

Library

  • Multi-folder library - point it at every music folder you own
  • Per-track memory travels with the file: A-B loops, speed, reverb
  • Sort options, compact/comfortable views, automatic refresh

Look and feel

  • Four skins in a built-in gallery: Light · Dark · Dark Warm · AMOLED (true pure-black for OLED screens)
  • Your chosen skin sticks - wins over the OS theme, survives restarts
  • Glow-and-elevation design language: accent glows, lifted surfaces, consistent tokens everywhere
  • Live waveform seek bar drawn from your actual audio - see the loud parts before you jump

Window & modes

  • Custom frameless window with its own title bar and menu bar - Alt toggles the menu
  • Full mode for library work, mini mode for focused listening (player card over queue, Ctrl+M flips)
  • Sleep blocker, notifications, automatic update checker

Settings

  • Organised the way you’d look for it: library, look and feel, playback engine - no config-file spelunking

Keyboard shortcuts

← / → Seek 10 seconds

What it is / what it is not

It is a fast, focused Windows player for listening and practice · It is not cross-platform (Windows 10/11 64-bit only) · No telemetry, no account, no network needed for playback - your files stay yours, on your machine.

Requirements & install (Windows)

Windows 10/11, 64-bit - the only supported platform. Build the Windows installer on this machine with vp install then vp run tauri build (NSIS installer lands in src-tauri/target/release/bundle/nsis/), run it, add library folders in Settings → Library. No account, no server, no network needed for playback.

Development setup

vp install            # install dependencies
vp run tauri dev      # Vite + Tauri with hot reload
vp check              # formatting + lint/typecheck
cargo test            # backend tests (inside src-tauri/)
vp run gen:types         # regenerate TS types from Rust
vp run gen:translations  # extract i18n strings
